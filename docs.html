Getting Started

v1.1.0

Installation

git clone https://github.com/deltathedumb/asmpython
cd asmpython
pip install .

Requirements

You'll need:

  • nasm ≥ 2.15 — assembler (auto-bootstrapped on Windows)
  • gcc — MinGW on Windows, system gcc on Linux
  • Python 3.11+ — to run the compiler

Your First Program

# hello.py
print("Hello, world!")
for i in range(5):
    print(i)
python -m asmpython hello.py
./hello          # Linux / hello.exe on Windows
How it works: The compiler reads Python source, runs through a complete lex → parse → sema → codegen pipeline, emits NASM assembly, and calls nasm + gcc to produce a standalone binary with zero Python runtime dependencies.

Key Features

🚀 Zero Runtime Overhead

No VM, no interpreter, no garbage collector. Native code compiled directly to x86-64 assembly.

📦 Self-Contained

Single binary. No Python installation needed. Ship your app anywhere.

🔧 Full Python Subset

Classes, exceptions, pattern matching, generators, comprehensions, decorators, and more.

🎯 Multiple Targets

Windows, Linux, freestanding (bare-metal), and 16-bit boot sector support.

📚 Rich Stdlib

math, re, json, csv, collections, datetime, and many more — all pure Python, all compiled.

⚡ Fast Compilation

Single-pass compiler. Large programs compile in seconds.

Language Support

Core Types

asmpython supports a rich type system optimized for compilation:

Type Representation Notes
int 64-bit signed No bignum. Supports hex, binary, octal, underscores. Floor division like CPython.
float IEEE-754 double Auto-promoted in mixed arithmetic. Division always returns float.
str Immutable UTF-8 Rich string methods, f-strings with format specs, slicing with step.
list[T] Dynamic array Homogeneous element type. Supports nested lists and dicts.
dict[K,V] Hash table String keys, insertion-ordered, open-addressed hashing.
tuple Fixed-size Heterogeneous. Used for multi-return and tuple unpacking.

Control Flow

Full support for:

  • if / elif / else
  • while with break, continue, and else clause
  • for loops with tuple unpacking
  • match / case pattern matching (PEP 634)
  • Ternary operator: x if cond else y
  • Walrus operator: if (x := expr) (PEP 572)

Functions & Classes

Full object-oriented programming:

  • Functions with default args, *args, type annotations
  • Classes with single inheritance, __init__, super()
  • Properties with @property and .setter
  • Static methods and class variables
  • Dunder methods: __str__, __len__, __getitem__, etc.
  • Decorators: @staticmethod, @property, custom decorators

Advanced Features

  • List/dict/set comprehensions and generator expressions
  • Exception handling with try / except / finally
  • Context managers: with statement, __enter__ / __exit__
  • Closures and nested functions with proper free-variable capture
  • Inline assembly with asm { ... }

Standard Library

All modules are implemented in pure Python and fully compiled into your executable.

Compilation Targets

Windows (PE64)

.exe binaries linked against msvcrt. Embed resources and icons.

Linux (ELF64)

ELF binaries linked against glibc. Full POSIX API support.

Bare-Metal (Multiboot1)

Bootable kernel for QEMU. No OS. Direct hardware access.

16-bit Boot

BIOS boot sector → 64-bit long mode. Raw disk images.

Compiler Options

python -m asmpython <source.py> [options]

# Output and compilation
-o <path>                 Output path
--target <t>              windows | linux | freestanding | freestanding16
--emit-asm                 Emit .asm only (no assemble/link)
--keep                     Keep intermediate .obj/.o files

# Diagnostics
--check                    Frontend only (lex/parse/sema)
--json                     Machine-readable JSON diagnostics
--explain <CODE>          Print error description

# Linking and deployment
--use-runtime-lib          Link prebuilt runtime (~50% smaller .asm)
--onefile                  Single binary (default)
--onedir                   Bundle exe + runtime library
--type executable          Executable (default)
--type library             Shared library (.dll/.so)
--icon <path>             Embed icon (Windows only)
