asmpython

Compile Python source to native x86-64 executables via NASM — no VM, no interpreter, no pip dependencies at runtime.

platformWindows · Linux
python3.11+
licenseMIT

asmpython is a single-pass ahead-of-time compiler. It takes idiomatic Python and produces NASM assembly, which is assembled by nasm and linked by gcc into a standalone native binary. There is no virtual machine, no bytecode, and no Python runtime shipped with your output.

Three output targets are supported:

  • Windows (PE64) — .exe linked against msvcrt
  • Linux (ELF64) — ELF binary linked against libc
  • Freestanding (Multiboot1) — bare-metal kernel binary, no OS, boots in QEMU
  • Freestanding 16-bit boot image — raw BIOS-bootable disk image (16-bit boot sector → long mode), no bootloader

Installation #

From source

# requires Python 3.11+ and git
git clone https://github.com/mabel/asmpython
cd asmpython
pip install .

Quick start #

python
# hello.py
print("Hello, world!")

for i in range(5):
    print(i)
shell
python -m asmpython hello.py
./hello          # Linux / hello.exe on Windows

Freestanding kernel in QEMU

python
# kernel.py
print("Hello from asmpython OS!")
print(42)
print("Booted successfully.")
shell
python -m asmpython kernel.py --target freestanding -o kernel.bin
qemu-system-x86_64 -kernel kernel.bin -serial stdio -display none
output
Hello from asmpython OS!
42
Booted successfully.

Strings #

Literals

Single-quoted, double-quoted, and triple-quoted ("""...""" / '''...'''). Standard escapes: \n \t \r \0 \\ \' \". F-strings: f"x={x}", with optional format specs (f"{x:.2f}", f"{n:05d}", f"{n:x}") and conversions (f"{x!r}", f"{x!s}", f"{x!a}") — !r/!a use repr() (quoting strings, preferring a class's __repr__ over __str__).

Format specs also support the [[fill]align]width prefix from Python's mini-language, for str, int, float, and bool values: align is one of < (left), > (right), or ^ (center), with an optional fill character before it (default space), e.g. f"{name:>10}", f"{name:*^11}", f"{n:0>5}". A bare width with no align character (f"{name:10}") defaults to left-alignment for strings. str values ignore numeric-only specs like .2f; a non-empty spec on a bool formats the underlying int (0/1), matching CPython's bool.__format__.

int values also support the binary type b (e.g. f"{n:b}"), with an optional # alternate form adding a 0b prefix (f"{n:#b}") and an optional zero-padded width (f"{n:#010b}") -- the sign and prefix are counted toward the width, matching CPython.

The , and _ grouping options insert thousands separators into the integer part of int/float values, e.g. f"{1234567:,}" -> "1,234,567", f"{1234567:_}" -> "1_234_567", f"{amount:,.2f}" -> "1,234,567.89"; combinable with alignment/width (f"{n:>15,}") and with a zero-padded width (f"{n:015,}" -> "000,001,234,567"), matching CPython's separator-aware zero-padding.

str values also support a .precision spec, which truncates to the first precision characters (a no-op if the string is already shorter), e.g. f"{name:.5}", combinable with alignment/width and the s type char (f"{name:>10.5}", f"{name:10.5s}").

"...".format(args) (literal format string): positional fields {} (auto-numbered) and {0}/{1} (explicit index), named fields {name} matching keyword arguments ("{name} is {age}".format(name="bob", age=5), freely mixable with positional fields), {{/}} for literal braces, and the same !r/!s/!a conversions and :format-spec mini-language as f-strings, e.g. "{:>10}".format(name), "{0:.2f}".format(pi), "{!r}".format(name), "{0!r:>8}".format(name), "{val:,}".format(val=n). Attribute/index access in fields ({0.attr}, {0[0]}) is not supported.

Collections #

Lists

python
xs = [1, 2, 3]
xs.append(99)
last = xs.pop()
xs[0] = 10
for x in xs: print(x)
print(xs[-1], xs[1:3])

Heap-allocated with stable header. Supports int, str, float elements (homogeneous). Negative indices, slicing with step, .copy(), comprehensions. .sort(key=?, reverse=?) sorts in place; key= takes a lambda (literal or name-bound) returning str or int, and reverse=True reverses the result. del xs[i] removes the element at i (negative indices supported), shifting later elements down.

Dicts

python
d = {"a": 1, "b": 2}
d["c"] = 3
val = d.get("x", -1)
for k, v in d.items(): print(k, v)
merged = d | {"d": 4}   # new dict; right side wins on key conflicts
d |= {"e": 5}      # merge in place
combo = {**d, "f": 6}  # dict unpacking; later entries win

Open-addressed hashtable (FNV-1a), stable header, load factor 3/4. str keys. Methods: .get, .contains, .keys(), .values(), .items(), .update(). Dict comprehensions supported. del d[k] removes the entry, raising KeyError if absent. d1 | d2 (PEP 584) builds a fresh dict containing d1's entries with d2's merged on top (d2's values win on conflicting keys); d1 |= d2 merges d2 into d1 in place. {**d1, "k": v, **d2} (PEP 448) builds a dict literal by merging zero or more **other spreads (each must be dict-typed) together with any explicit key: value pairs, all in source order — later entries win on key conflicts, and neither the literal's operands nor any spread source dicts are mutated. Dicts are insertion-ordered (matching CPython 3.7+): printing, iteration (for k in d), .keys()/.values()/.items(), and comprehensions all visit entries in the order their keys were first inserted, independent of hashtable bucket order; a key's position is preserved across updates and is closed up on del/.pop(), with new keys appended at the end.

Sets

python
s = {"a", "b", "c"}
s.add("d")
print("b" in s)
s.discard("a")
fs = frozenset(s)

Sets are str-keyed (backed by the same hashtable as dicts); {1, 2, 3} and .add()/.discard()/.remove() of non-str elements are rejected at compile time. Methods: .add(), .discard(), .remove(), .copy(), .pop(), .union(), .intersection(), .difference(), .update(), .clear().

Tuples

python
a, b = 1, 2          # unpacking assignment
a, b = b, a          # swap — RHS evaluated before LHS stores
xs[0], xs[1] = xs[1], xs[0]  # swap list elements
self.x, self.y = self.y, self.x  # swap instance attributes
for i, x in enumerate(xs): print(i, x)
for i, x in enumerate(xs, 1): print(i, x)  # start counting from 1
for a, b in zip(xs, ys): print(a, b)
a, *rest = xs        # starred unpack: rest = xs[1:]
*init, last = xs     # init = xs[:-1]
first, *mid, last = xs

Tuple-assignment targets may be plain names, subscripts, or attributes (in any mix); every value on the right is evaluated before any store happens, so swaps work without a temporary. The single-iterable unpack form (a, b = some_list) requires plain-name targets.

A single starred target (*rest, PEP 3132) may appear anywhere among the unpack targets and collects the leftover elements into a new list of the same element kind; this form requires the right-hand side to be a list.

Control flow #

python
# if / elif / else
if x > 0:
    print("positive")
elif x == 0:
    print("zero")
else:
    print("negative")

# while with break / continue
while i < n:
    if i == 5: break
    if i % 2 == 0: continue
    i += 1

# for
for i in range(10):          # range(n)
for i in range(2, 20, 2):   # range(start, stop, step)
for x in my_list:
for k in my_dict:
for ch in my_string:

# for/while ... else: runs only if the loop finished without `break`
for x in my_list:
    if x == target: break
else:
    print("not found")

# ternary
label = "even" if n % 2 == 0 else "odd"

# walrus operator: assign and use the value in one expression
if (count := len(data)) > 3:
    print(count)

# assert
assert x > 0, "must be positive"

target := value (the "walrus operator") evaluates value, assigns it to target, and the whole expression yields that value — usable anywhere an expression is, e.g. while (line := f()): or x if (n := len(s)) > 3 else y. Inside a list/dict comprehension, the target binds in the enclosing scope (per PEP 572), unlike the comprehension's own loop variable: [y := v * 2 for v in vals] leaves y set to the last value afterward.

Functions #

python
def greet(name: str, times: int = 1) -> str:
    return (name + " ") * times

def variadic(*args):
    for a in args:
        print(a)

# first-class
f = greet
print(f("hi", 3))

Default arguments (int, str, float, True, False, None literals), *args, type annotations (parsed, not enforced). Recursion at any depth. Decorators.

Parameters and instance fields don't need type annotations: when a parameter has no annotation and no default, its type is inferred from call-site arguments (string/float/list/dict/tuple literals, f-strings, or constructor calls), and a function that returns that parameter unchanged inherits its type too. This also makes self.x = param in __init__ infer the right field type. A parameter inferred this way needs every call site that gives static evidence to agree on one type; ambiguous or conflicting parameters fall back to int and need an explicit annotation.

*expr argument unpacking at call sites (f(*t)) is supported when expr is a tuple of statically-known shape — a name, subscript, or attribute bound to a tuple literal (or a list[tuple[...]] element). Each slot is spliced in as its own positional argument at compile time; there's no runtime varargs, so unpacking a Call result directly (f(*g())) isn't supported — assign it to a variable first.

Classes #

python
class Shape:
    def __init__(self, name):
        self.name = name

    def area(self) -> int:
        return 0

class Square(Shape):
    def __init__(self, side):
        super().__init__("square")
        self.side = side

    def area(self) -> int:
        return self.side * self.side

    def __str__(self) -> str:
        return f"Square({self.side})"

sq = Square(5)
print(sq.area())     # 25
print(str(sq))       # Square(5)
print(isinstance(sq, Shape))  # 1

Single inheritance, __init__, __str__, super(), instance attributes (any type), isinstance, hasattr/getattr.

Static methods & class variables

python
class Config:
    version = 5            # class variable (static constant)
    name = "app"

    @staticmethod
    def banner(title: str) -> str:
        return f"== {title} =="

print(Config.version)          # 5
print(Config.banner("hi"))     # == hi ==
Config.version += 1
print(Config.version)          # 6

@staticmethod methods are called on the class (Config.banner(...)) with no implicit receiver. Class variables (name = value in the class body, on a non-@dataclass class) are static constants stored once and read/written through the class — Config.version, including augmented assignment. @classmethod is accepted, though a class-method body that mutates class state through cls is not fully supported yet.

Properties

python
class Box:
    def __init__(self, w: int, h: int) -> None:
        self.w = w
        self.h = h

    @property
    def area(self) -> int:
        return self.w * self.h

b = Box(3, 4)
print(b.area)  # 12, computed on access

A @property-decorated method is called automatically whenever its name is read as an attribute (b.area), including through inheritance and virtual dispatch. A matching @x.setter method turns obj.x = value into a call to that setter; assigning to a property with no setter raises a compile-time error, matching CPython's AttributeError.

python
class Temperature:
    def __init__(self, celsius: int) -> None:
        self._celsius = celsius

    @property
    def celsius(self) -> int:
        return self._celsius

    @celsius.setter
    def celsius(self, value: int) -> None:
        self._celsius = value

t = Temperature(20)
t.celsius = 100  # calls the setter
print(t.celsius)  # 100, via the getter

Exceptions #

python
def parse(s):
    if len(s) == 0:
        raise ValueError("empty input")
    return int(s)

try:
    n = parse("")
except ValueError as e:
    print("error:", e)
finally:
    print("done")

try:
    xs[99]
except TypeError:
    print("type")
except (KeyError, IndexError) as e:
    print("lookup error:", e)

try/except/else/finally, raise (string or exception object), re-raise. Every exception carries a runtime type id, and each except ExcType: / except (ExcType1, ExcType2): clause is checked against it in source order, including builtin hierarchy (e.g. except LookupError: catches a raised KeyError or IndexError; except ArithmeticError: catches ZeroDivisionError). The first matching clause runs; if none match, finally still runs and the exception propagates to an enclosing handler (or terminates the program if uncaught). A bare except: matches anything, and a raise of a plain string always matches the first clause (typed or not), preserving the old untyped-exception behaviour. Stack unwinding via setjmp/longjmp at arbitrary call depth.

Inline assembly #

The @assembly_func decorator turns the function docstring into raw NASM emitted verbatim as the function body.

python
from asmpython.assembly import assembly_func

@assembly_func
def popcnt(x: int) -> int:
    """
    popcnt rax, rdi     ; SysV: x in rdi  (Win64: rcx)
    ret
    """

@assembly_func
def add(a: int, b: int) -> int:
    """
    mov  rax, rdi
    add  rax, rsi
    ret
    """

print(popcnt(0b10110111))   # 6
print(add(3, 4))             # 7

Arguments arrive in the platform's integer registers (SysV: rdi/rsi/…; Win64: rcx/rdx/…). Return value in rax. Works under CPython too — the decorator returns a stub that raises if called at the Python level.

Assembly builder #

The Assembly class provides a chainable Python API for generating NASM programmatically. Over 150 instruction methods including full SSE/AVX, atomics, and system calls.

python
from asmpython.assembly import Assembly

a = Assembly()
(a
  .global_("entry")
  .label("entry")
  .push("rbp")
  .mov("rbp", "rsp")
  .xor("eax", "eax")
  .inc("eax")
  .pop("rbp")
  .ret()
)
print(a.emit())   # prints NASM source

Categories: data transfer, arithmetic, logic, shifts, control flow, call/ret, string ops, SIMD (SSE/SSE2/SSE4/AVX/AVX2), atomics (lock_xadd, cmpxchg), system (syscall, rdmsr, wrmsr, cpuid, rdtsc), directives (db, dq, resb, section, align, extern, global_).

Assembly packages (.asmpkg) #

An assembly package is a name.asmpkg directory containing a manifest.txt (exported symbols + signatures) and one or more .asm files. Use include() to link one into your program:

python
from asmpython.assembly import include

include("mathx")   # links mathx.asmpkg from same directory as source

print(square(9))  # symbol exported by mathx

The package's NASM is concatenated into the generated .asm and its exported symbols become directly callable. Useful for shipping hand-optimised routines or freestanding runtime components.

Target: Windows (PE64) #

  • Format: nasm -f win64, linked with MinGW gcc
  • ABI: Microsoft x64 — args in rcx/rdx/r8/r9, 32-byte shadow space, 16-byte stack alignment
  • Runtime: msvcrt (printf, malloc, …)
  • Output: .exe

Target: Linux (ELF64) #

  • Format: nasm -f elf64, linked with system gcc
  • ABI: System V AMD64 — args in rdi/rsi/rdx/rcx/r8/r9
  • Runtime: libc
  • Output: ELF64 executable (no extension by default)

Target: Freestanding (Multiboot1) #

  • Format: nasm -f bin — flat binary, no linker
  • Multiboot1 AOUT kludge header — bootable by GRUB and QEMU -kernel
  • No libc, no OS — custom runtime only
  • Stack: 64 KB
  • Heap: 256 KB bump allocator
  • Long-mode setup: GDT, identity-mapped page tables (first 16 MB, 2 MB huge pages)
  • VGA text mode output (80×25)
  • COM1 serial output (38400 8N1) — all print() output mirrored to serial
shell
# Build and test headlessly
python -m asmpython kernel.py --target freestanding -o kernel.bin
qemu-system-x86_64 -kernel kernel.bin -serial stdio -display none
All print() calls write to both the VGA framebuffer and COM1 serial. Use -serial stdio to see output in your terminal, or -serial file:out.txt to capture it.

Target: Freestanding 16-bit boot image #

Same bare-metal kernel as freestanding, but packaged as a raw, BIOS-bootable disk image instead of a Multiboot1 kernel — no GRUB or -kernel needed. The first 512 bytes are a real-mode (16-bit) boot sector ending in the 0xAA55 signature, exactly how a PC starts.

  • Format: nasm -f bin — flat .img, bootable from disk/USB
  • 16-bit boot sector: loads the kernel via INT 13h (LBA), enables A20
  • Switches 16-bit real → 32-bit protected → 64-bit long mode, then runs the same 64-bit kernel
  • Identical runtime to freestanding (VGA + COM1, 64 KB stack, 256 KB heap)
shell
python -m asmpython kernel.py --target freestanding16 -o boot.img
qemu-system-x86_64 -drive format=raw,file=boot.img -serial stdio -display none
Reads a fixed span off the boot disk, so the build pads the image to a whole number of sectors. Under QEMU's raw disk this Just Works; for real hardware, write the .img to a USB stick with dd.

Pipeline

  1. Lex — indent-aware tokenizer; emits synthetic INDENT/DEDENT; tracks bracket depth to suppress newlines inside (/[/{
  2. Parse — recursive-descent; every node carries a SourcePos
  3. Sema — name resolution, arity checks, type propagation, import binding against stdlib/asmlib registries
  4. Codegen — single-pass tree walk emitting NASM; locals pre-collected for fixed RBP-relative slots; runtime helpers emitted inline
  5. Driver — writes .asm, runs nasm, runs gcc as linker driver; cleans intermediates
